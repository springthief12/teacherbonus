# 그때 그 노래

멜론 연도별 차트 노래를 여러 명이 동시에 맞히는 실시간 웹 게임입니다.
방에 모여 연도를 고르면 그해 차트 곡이 섞여 나오고, 채팅창에 제목을 가장 먼저 친 사람이 점수를 가져갑니다.

- 화면 구성은 끄투처럼: 가운데 문제 화면, 아래 플레이어 캐릭터 카드, 맨 아래 채팅
- 게임 규칙은 스타크래프트 노래맞히기 유즈맵처럼: 선착순 정답, 정답 뒤에도 노래를 계속 듣다가 넘기기

> 지금은 **초안(v0.1)** 입니다. 2010년 샘플 40곡만 들어 있고, 멜론 실제 순위와는 다릅니다.

## 교실에서 켜는 법

선생님 PC 한 대가 서버가 되고, 같은 와이파이에 있는 학생 기기(크롬북·태블릿·폰)가 접속합니다.
이 게임은 서버가 필요해서 티처툴 웹사이트(GitHub Pages)에서는 바로 열리지 않습니다.

1. 선생님 PC에 [Node.js](https://nodejs.org) LTS 버전을 설치합니다. (처음 한 번)
2. 이 `song-quiz` 폴더를 PC에 내려받습니다. 저장소 페이지의 Code → Download ZIP 후 압축을 풀면 됩니다.
3. 윈도우는 `start-windows.bat`, 맥은 `start-mac.command` 를 더블클릭합니다.
   처음 한 번은 필요한 파일을 내려받느라 1~2분 걸립니다.
4. 검은 창에 뜨는 `같은 와이파이: http://192.168.x.x:3000` 주소를 칠판에 적어 주면 학생들이 그 주소로 들어옵니다.
5. 윈도우 방화벽 창이 뜨면 **허용**을 누릅니다. 학생 기기에서 안 열리면 대부분 이 단계 문제입니다.

명령어로 실행하려면:

```bash
npm install
npm start          # http://localhost:3000
```

| 환경 변수 | 설명 |
| --- | --- |
| `PORT` | 서버 포트 (기본 3000) |
| `YT_API_KEY` | 유튜브 Data API 키. 있으면 공식 API로 영상을 찾고, 없으면 키 없이 검색(yt-search)합니다 |

## 게임 흐름

1. 로비에서 닉네임과 카세트 캐릭터(색·표정·소품)를 고르고 방을 만들거나 들어갑니다. 한 방 최대 8명.
2. 방장이 연도(여러 해 섞기 가능)와 규칙을 고르고 시작합니다.
3. 곡이 나오면 채팅창에 제목을 입력합니다. 오답은 채팅으로 모두에게 보이고, 정답은 가려집니다.
4. 시간이 지나면 힌트가 열립니다: 연도 → 가수(35%) → 제목 초성(65%).
5. 누군가 맞히면 정답이 공개되고 노래가 계속 나옵니다. 넘기기 투표가 모이면 바로 다음 곡으로 갑니다.
6. 마지막 곡이 끝나면 순위를 보여 주고, 방장이 다시 시작할 수 있습니다.

넘기기: `넘기기` 버튼, 채팅창 밖에서 `K`, 또는 채팅에 `!s` / `!스킵`.

### 방 설정

| 항목 | 선택지 | 기본 |
| --- | --- | --- |
| 곡 수 | 10 · 20 · 30 · 50 | 20 |
| 제한 시간 | 20 · 30 · 45 · 60초 | 30초 |
| 재생 위치 | 전주부터 · 중간부터 | 전주부터 |
| 넘기기 | 과반수 투표 · 한 명이라도 · 방장만 | 과반수 |
| 점수 | 정답 10점 · 빠를수록 더(5 + 남은 초) | 10점 |
| 정답 후 듣기 | 5 · 10 · 15 · 30초 | 15초 |

### 정답 판정

대소문자, 띄어쓰기, 문장부호는 무시합니다. 괄호 속 부제는 따로도 인정합니다.
예) `숨 (Breath)` → "숨", "breath", "숨 breath" 모두 정답.
영어 제목의 한글 표기(예: "배드걸굿걸")는 차트 파일의 `aliases`에 적어 둡니다.

## 차트 데이터

`data/charts/<연도>.json` 파일 하나가 한 해 차트입니다. 파일이 있는 연도만 방에서 고를 수 있습니다.

```json
{
  "year": 2010,
  "source": "melon",
  "verified": true,
  "songs": [
    { "rank": 1, "title": "Bad Girl Good Girl", "artist": "miss A", "aliases": ["배드걸굿걸"], "youtubeId": "선택", "start": 0, "highlight": 55 }
  ]
}
```

- `youtubeId`: 직접 지정하면 검색을 건너뜁니다. 엉뚱한 영상이 나올 때 고쳐 넣으세요.
- `start` / `highlight`: 전주부터·중간부터 모드에서 시작할 초. 없으면 0초 / 45~75초 사이 무작위.

텍스트 목록으로 한 번에 만들기:

```bash
node scripts/import-chart.js 2011 chart-2011.txt
```

한 줄에 `1. 제목 - 가수`, `제목<Tab>가수`(엑셀 복사) 같은 형식이면 됩니다.

## 음원

곡마다 유튜브 영상을 찾아 화면 뒤에 숨겨서 재생하고, 정답이 공개되면 뮤직비디오가 노래방 배경처럼 비칩니다.
찾은 영상 ID는 `data/youtube-cache.json` 에 저장해 다음부터 다시 찾지 않습니다.
삭제됐거나 퍼가기가 막힌 영상이면 다음 후보로 자동으로 바꿉니다.

## 구조

```
server/
  index.js     웹 서버 + 소켓 연결, 로비/방 관리
  room.js      방 하나의 게임 진행 (라운드, 정답, 힌트, 넘기기, 점수)
  answer.js    정답 비교, 초성 힌트
  charts.js    연도별 차트 읽기, 셔플
  youtube.js   곡 → 유튜브 영상 찾기 + 캐시
public/
  index.html   로비 · 방 화면
  css/style.css
  js/app.js    화면과 소켓 이벤트
  js/avatar.js 카세트 캐릭터 그리기
  js/player.js 유튜브 재생기 (서버 시각에 맞춰 동시 재생)
scripts/import-chart.js
test/flow.test.js  3명 접속 흐름 테스트 (서버를 켠 뒤 npm test)
start-windows.bat  윈도우 더블클릭 실행
start-mac.command  맥 더블클릭 실행
```
