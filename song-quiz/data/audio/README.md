# 음원 파일 넣는 곳

여기에 음원 파일을 넣으면 유튜브 대신 이 파일을 재생합니다. 광고가 없고, 모든 기기에서 같은 구간이 정확히 나옵니다.

```
data/audio/
  2010/
    1.mp3     ← 2010년 1위 곡
    2.mp3
    ...
    50.mp3
```

- 파일 이름은 순위 숫자입니다. `01.mp3`처럼 앞에 0을 붙여도 됩니다.
- mp3, m4a, ogg, wav, aac를 읽습니다.
- 파일이 없는 곡은 자동으로 유튜브(소리만)로 재생합니다.
- 서버를 다시 켤 필요 없이 다음 곡부터 바로 반영됩니다.

이 폴더의 음원은 저작권 때문에 깃허브에 올라가지 않도록 막아 두었습니다.
선생님이 직접 구매·보유한 파일을 수업용 PC에만 넣어 쓰세요.
